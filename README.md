## 同步 chinese-poetry 到 markdown 文件

1. 下载 chinese-poetry 仓库
2. 把 `chinese-poetry` 目录放到 `aspoem` 根目录下
3. 运行以下命令生成 markdown 文件

```shell
pnpm gen:markdown
```

## 正文

- 離離原上草，一歲一枯榮。
- 野火燒不盡，春風吹又生。
- 遠芳侵古道，晴翠接荒城。
- 又送王孫去，萋萋滿別情。
